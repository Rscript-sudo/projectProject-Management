# 文档生成流程（精简版）

> 最近一次梳理：2026-08-19。本文是简版；详细版本在 Claude 会话内，未落盘。

## 一、核心路径（用户视角）

```
用户在 ProjectView.tsx 输入框打字
  → 点发送（ProjectView.tsx:519-525）
  → identifyDocType() 识别 docType（aiService.ts:661）
  → buildDocPrompt() 拼装 system prompt（aiService.ts:1290）
  → window.electronAPI.callAIStream(ipcParams)（preload.cjs:19）
  → 主进程 ai:stream handler（shell.mjs:270）→ SSE 回流
  → 前端 onAIStreamChunk 累加（ProjectView.tsx:543）
  → ★ 第 2 层防线（流式）：反编造清洗（ProjectView.tsx:569-573）
  → 字数补足（minWords 不够 → 再走一次 callAIStream，最多 1 次）
  → 字段清洗：sanitizeFieldValue + sanitizeLetterStyle
  → 用户点【保存】（ProjectView.tsx:1415 → handleSave:776）
  → window.electronAPI.saveDoc({...})（preload.cjs:16）
  → 主进程 fs:saveDoc handler（doc.mjs:30）
  → 落盘 docx
```

## 二、主进程 fs:saveDoc 内部流程（doc.mjs:30-246）

```
1. ★ 第 3 层防线：主进程入口反编造再过一遍（doc.mjs:33-39）
   postProcessTimeFields(postProcessFabricationGuard(content).content)

2. ★ 第 4 层防线：正式件硬门禁（doc.mjs:51-58）
   validateDeliverableContent(content, projectType)
   命中 markers / forbiddenTerms → 拒绝

3. ★ 第 5 层防线：占位符白名单扫描（doc.mjs:69-75）
   scanForLeftoverPlaceholders(content)
   命中未白名单 → 拒绝

4. 文件名生成（filename.mjs:167，虚竹 v2.0）
   {YYYYMMDD}_{DOC_CODE}_{PROJECT_CODE}_{SUMMARY}_V{n}.docx

5. 路径构造（doc.mjs:99-108）
   isPathSafe(savePath) 兜底，临时文件 .draft 后缀

6. 模板解析：findTemplate 三级回退（templateService.mjs:139）
   优先级：项目 templateOverrides → 企业库 libraryTemplate → 系统预置

7. previewNumber 占号预览（numbering.mjs:259，不持久化）

8. buildPlaceholderData 拼字典（templateService.mjs:343）
   expandAliases() + parseSections() + sanitizeBodyContent()

9. ★ 三选一渲染分支（doc.mjs:154-173）
   if engine === 'xlsx':
     renderXlsxTemplate()         ← xlsx 库按单元格映射
   elif useStructuredSystemLayout:
     validateStructuredSystemData() ★ 必填字段门禁
     renderStructuredSystemDocument() ← docx 库代码生成版式
   else:
     renderTemplate()             ← docxtemplater 替换真模板占位符

10. ★ 第 6 层防线：渲染后 buffer 扫占位符（templateService.mjs:512-528）
    从 buffer 解 zip 读 xml，扫 {{xxx}} → 白名单过滤
    命中非白名单 → 拒绝

11. formatDocx GB/T 9704 格式化（templateService.mjs:831）
    字体兼容 + 行距 560 + 页边距 2098/1984/1587/1474 twips

12. ★ 第 7 层防线：渲染后解 zip 再 validate（doc.mjs:184-191）
    validateDeliverableContent(renderedText, projectType)
    兜底防模板默认值绕过

13. getAndIncrementNumber 真占号（numbering.mjs:227，TOCTOU 锁）
    编号变了 → 用真号再渲染一次

14. fs.renameSync(draft → 正式路径)（doc.mjs:205，原子写）

15. 双台账登记（doc.mjs:206-207）
    JSON 台账（updateLedger in shared.mjs:174）
    SQLite 业务台账（recordIssuedDocument in repo.mjs:517）
```

## 四、三条渲染分支

| 引擎 | 触发条件 | 函数 | 文件:行 |
|---|---|---|---|
| **xlsx** | `config.engine === 'xlsx'` | `renderXlsxTemplate` | `templateService.mjs:662` |
| **结构化系统版式** | 无 override + 无 libraryTemplate + 在白名单 | `renderStructuredSystemDocument` | `templateService.mjs:576` |
| **docxtemplater 真模板** | 项目/企业库覆盖了模板 | `renderTemplate` | `templateService.mjs:440` |

**白名单**：`STRUCTURED_SYSTEM_DOC_TYPES = new Set(['监理日志', '监理周报', '监理月报', '整改通知书', '安全通知书', '工程联系单', '进度分析报告'])`（`templateService.mjs:541-543`）

> ⚠️ **已知设计行为**：白名单内 7 类文种的"系统预置 docx 模板"默认不会被使用（即便 `templates/<dir>/<doc>模版.docx` 文件存在）。要让真模板生效，必须满足：项目级 `templateOverrides[docType]` 或 企业模板库导入。
>
> `templates/06_监理联系单/监理联系单模版.docx` 等就是这种情况。

## 六、PDF 导出差异（fs:exportPDF）

- 走相同反编造防线（1/3/4/5）
- 不走第 6/7 层（PDF 不渲染后扫）
- **不占文号**（避免 Word/PDF 重复登记）
- **不写台账**
- mammoth 转 HTML → 套 A4 打印样式 → BrowserWindow.printToPDF

## 七、相关文件位置

- 模板配置：`templates/<docType_dir>/config.json`
- 系统预置模板：`templates/<docType_dir>/<name>模版.docx`
- 项目级覆盖：`项目目录/project.config.json.templateOverrides[docType]`
- 企业模板库：`~/Library/Application Support/项目文档管理系统/template-library/template-registry.json`（macOS）
- 字段别名真源：`src/shared/field-aliases.json`
- 项目类型 SOP 路由：`src/shared/project-type-router.json`
- 字数下限：`src/shared/doc-type-min-words.json`
- SOP JSON：`src/shared/sop/<projectType>/*.json`
