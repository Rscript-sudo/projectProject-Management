## 一、核心路径（用户视角）

```
用户在 ProjectView.tsx 输入框打字
  → 点发送（handleSend, ProjectView.tsx:564）
  → identifyDocType() 识别 docType（aiService.ts）
  → buildDocPrompt() 拼装 system prompt（aiService.ts:1544）
  → window.electronAPI.callAIStream(ipcParams)
  → 主进程 ai:stream handler（shell.mjs）→ SSE 回流
  → 前端累加 chunk
  → ★ 第 2 层防线（流式）：sanitizeFullPipeline 统一清洗（ProjectView.tsx:886）
      顺序：stripThinking → stripCalibration → 反编造守门员 → 时间字段
            → 事由前缀 → 信件语体 → 日志参与者
  → 字数补足（minWords 不够 → 再走一次 callAIStream，最多 1 次）
      续写中间态也走 sanitizeFullPipeline（ProjectView.tsx:918/935）
  → 用户点【保存】（handleSave, ProjectView.tsx:1079）
  → window.electronAPI.saveDoc({...})
  → 主进程 fs:saveDoc handler（doc.mjs:42）
  → 落盘 docx
```

> v1.3.1 变更：流式主路径 / 续写路径 / 非流式降级三路径统一用 `sanitizeFullPipeline`（原分散调用 `sanitizeFieldValue`/`sanitizeLetterStyle`，续写中间态漏 sanitize 已修）。

## 二、主进程 fs:saveDoc 内部流程（doc.mjs:42-280）

```
1. ★ 第 3 层防线：主进程入口反编造再过一遍（doc.mjs:45）
   postProcessFabricationGuard(content)

2. ★ 第 4 层防线：正式件硬门禁（doc.mjs:79）
   validateDeliverableContent(content)
   命中 markers / forbiddenTerms → 拒绝

3. ★ 第 5 层防线：占位符白名单扫描（doc.mjs:96）
   scanForLeftoverPlaceholders(content)
   命中未白名单 → 拒绝

4. 文件名生成（filename.mjs，虚竹 v2.0）
   {YYYYMMDD}_{DOC_CODE}_{PROJECT_CODE}_{SUMMARY}_V{n}.docx

5. 路径构造（doc.mjs）
   isPathSafe(savePath) 兜底，临时文件 .draft 后缀

6. 模板解析：findTemplate 三级回退（templateService.mjs:158）
   优先级：项目 templateOverrides → 企业库 libraryTemplate → 系统预置

7. previewNumber 占号预览（numbering.mjs，不持久化）

8. buildPlaceholderData 拼字典（templateService.mjs:342）
   expandAliases() + parseSections() + sanitizeBodyContent()

9. ★ 三选一渲染分支（doc.mjs:195-201）
   if engine === 'xlsx':
     renderXlsxTemplate()         ← xlsx 库按单元格映射
   elif useStructuredSystemLayout:
     validateStructuredSystemData() ★ 必填字段门禁
     renderStructuredSystemDocument() ← docx 库代码生成版式
   else:
     renderTemplate()             ← docxtemplater 替换真模板占位符

10. ★ 第 6 层防线：渲染后 buffer 扫占位符（templateService.mjs）
    从 buffer 解 zip 读 xml，扫 {{xxx}} → 白名单过滤
    命中非白名单 → 拒绝

11. formatDocx GB/T 9704 格式化（templateService.mjs）
    字体兼容 + 行距 560 + 页边距 2098/1984/1587/1474 twips

12. ★ 第 7 层防线：渲染后解 zip 再 validate（doc.mjs:215/270）
    validateDeliverableContent(renderedText)
    兜底防模板默认值绕过

13. getAndIncrementNumber 真占号（numbering.mjs，TOCTOU 锁）
    编号变了 → 用真号再渲染一次

14. fs.renameSync(draft → 正式路径)（doc.mjs:228/239，原子写）

15. 双台账登记
    JSON 台账（updateLedger in shared.mjs）
    SQLite 业务台账（recordIssuedDocument in repo.mjs）
```

## 三、反编造 7 层防线总表

| # | 时机 | 函数 | 位置 |
|---|---|---|---|
| 1 | prompt 拼装 | `ANTI_FABRICATION_RULES`（10 节铁律，含防 prompt 注入第十条） | `aiService.ts:302` |
| 2 | 流式/非流式返回后 | `sanitizeFullPipeline`（统一管道） | `ProjectView.tsx:151`（定义）/ `886`（流式）/ `1009`（非流式） |
| 3 | 主进程 saveDoc 入口 | `postProcessFabricationGuard` + `postProcessTimeFields`（同源双实现） | `doc.mjs:45` / `shared/postProcess.mjs` |
| 4 | saveDoc 字数校验前 | `validateDeliverableContent`（markers + forbiddenTerms） | `doc.mjs:79` |
| 5 | saveDoc 渲染前 | `scanForLeftoverPlaceholders`（白名单） | `doc.mjs:96` |
| 6 | docxtemplater 渲染后 buffer | 渲染后解 zip 扫占位符 | `templateService.mjs` |
| 7 | saveDoc 落盘前 | `validateDeliverableContent(renderedText)` | `doc.mjs:215/270` |

**占位符白名单数据源**（`placeholderScan.mjs`）：
- `EXPECTED_PLACEHOLDER_RE` — 合法残留（`{{未指定时间}}` / `{{待补充：...}}` / `{{CURRENT_DATE}}`）
- `MANUAL_FILL_PLACEHOLDERS` — 12 项必填手动填充字段
- `getKnownAliases()` — 从 `src/shared/field-aliases.json` 读所有合法别名

## 四、三条渲染分支

| 引擎 | 触发条件 | 函数 | 位置 |
|---|---|---|---|
| **xlsx** | `config.engine === 'xlsx'` | `renderXlsxTemplate` | `templateService.mjs` |
| **结构化系统版式** | 无 override + 无 libraryTemplate + 在白名单 | `renderStructuredSystemDocument` | `templateService.mjs` |
| **docxtemplater 真模板** | 项目/企业库覆盖了模板 | `renderTemplate` | `templateService.mjs` |

**白名单**：`STRUCTURED_SYSTEM_DOC_TYPES = new Set(['监理日志', '监理周报', '监理月报', '整改通知书', '安全通知书', '工程联系单', '进度分析报告'])`（`templateService.mjs:540`）

> ⚠️ **已知设计行为**：白名单内 7 类文种的"系统预置 docx 模板"默认不会被使用（即便 `templates/<dir>/<doc>模版.docx` 文件存在）。要让真模板生效，必须满足：项目级 `templateOverrides[docType]` 或 企业模板库导入。
>
> `templates/06_监理联系单/监理联系单模版.docx` 等就是这种情况。

## 六、PDF 导出差异（fs:exportPDF）

- 走相同反编造防线（1/3/4/5）
- 不走第 6/7 层（PDF 不渲染后扫）
- **不占文号**（避免 Word/PDF 重复登记）
- **不写台账**
- mammoth 转 HTML → 套 A4 打印样式 → BrowserWindow.printToPDF

## 七、相关文件位置

- 模板配置：`templates/<docType_dir>/config.json`

- 字数下限：`src/shared/doc-type-min-words.json`
